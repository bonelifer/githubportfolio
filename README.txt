GitHub Portfolio 0.1.6-dev

Novidades desta versão:
- seção mais integrada ao visual do portal
- projetos em destaque fixados no topo
- cards destacados no portal e na página própria
- novo campo no ACP para título dos destaques
- novo campo no ACP para escolher quais repositórios ficam em destaque

Como usar os destaques:
- no ACP, preencha os nomes dos repositórios em “Projetos em destaque”
- aceite nomes separados por vírgula ou quebra de linha
- os destaques aparecem primeiro e respeitam a ordem digitada

Como atualizar:
- substitua os arquivos de mundophpbb/githubportfolio
- limpe o cache do phpBB
- atualize a extensão no ACP para aplicar a migration v_0_1_4

Observações:
- o limite do portal agora considera os destaques primeiro
- se houver destaques, eles ocupam até 2 posições no bloco do portal
- o botão Discussão continua funcionando normalmente
